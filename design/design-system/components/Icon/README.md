# Icon

Bộ biểu tượng nét mảnh 1.7px, khung 24px, màu theo chữ xung quanh.

- Truyền `name`: home, receipt, calendar, user, more, plus, check, chevron-right, search, wallet, alert. `size` mặc định 24.
- Biểu tượng đứng một mình (nút chỉ có biểu tượng) phải có `title` để trình đọc màn hình đọc được; biểu tượng đi kèm chữ thì bỏ `title`.
- Cần biểu tượng khác thì lấy từ bộ Lucide và đặt stroke-width 1.7 cho đồng bộ. Quán chưa có bộ biểu tượng riêng nên đây là bộ thay thế.
- Không dùng emoji thay biểu tượng.
