# Câu hỏi còn chờ

Cập nhật: 13/10/2026 sau Đợt 4. Trả lời xong câu nào thì chuyển sang `DECISIONS.md` và xoá khỏi đây.

## 1. Chuẩn bị máy để chạy local (anh làm)

- **PostgreSQL 16**: máy chưa có. Cần cài để chạy app ở local.
- **Git trên dòng lệnh**: máy có git đi kèm GitHub Desktop nhưng chưa nằm trong PATH. Nên cài Git for Windows để Claude Code dùng được lệnh git (hoặc chỉ dùng GitHub Desktop để đồng bộ).

## 2. Trước khi chạy thật trên Mắt Bão

- Tên miền (anh mua sau) và HTTPS: bắt buộc để có PWA và Web Push trên iPhone.
- Ngày chuyển hẳn từ Apple Calendar sang LINDY OS (nhập tay các lịch sắp tới, B15).
- Khoảng ngày dương lịch của mùa cọc Tết 2027 (19–28 tháng Chạp). Linh nhập trong Cài đặt.
- Tháng mở sổ; số dư mở sổ của Tiền mặt cs HTK và Tài khoản cs HTK.
- Lịch quán đóng cửa Tết 2027 (Linh nhập ở Cài đặt lịch → Ngày quán đóng cửa).
- Ngày vào làm, cách nhận lương (chuyển khoản / tiền mặt) của từng người; tháng bắt đầu tính lương trên app (Linh nhập ở Thêm → Nhân viên). Chạy song song với bảng lương Sheets ít nhất một tháng.
- Hệ số ngày lễ (Q30, hiện như ngày thường): chỉ cần khi anh muốn trả thêm ngày lễ.

## 3. Sau phản biện Đợt 3 (chờ anh quyết)

- **P62 — trả tip trước khi đối soát sao kê:** hiện Nhung trả tip tiền mặt cho thợ được ngay khi tip vừa ghi (tip ghi vào tài khoản ngân hàng, hiện ở "chuyển khoản chưa đối soát" khi chốt quỹ). Giữ như vậy, hay chỉ cho trả tip đã khớp sao kê (an toàn hơn, cuối ngày chậm hơn)?

## 4. Chưa cần ngay

- Ca nửa ngày (sáng hoặc chiều) tính 0,5 công hay 1 công. Hiện mọi người làm fulltime.
- Thời lượng chuẩn từng dịch vụ. Lịch đặt đã có mặc định 120 phút.
- Thuế, hóa đơn điện tử: chủ hỏi kế toán (ngoài phạm vi app).
- Logo mới (ngoài phạm vi app; đang dùng biểu tượng chữ L).
